# 需求：「服务器」tab —— 线条画风 3D 可交互机箱

## Goal

新建导航 tab **「服务器」**承载机箱体验（用户 2026-10-15 定案，机箱从首页 hero 归位到独立入口）：

- **首页**：只保留像素标题「树码空间」——「像素标题变机箱」的变形效果**直接移除**（已实施，`index.astro` 还原为 `PixelWaveTitle`）。
- **「服务器」tab**：机箱以**线条画风**呈现——按机箱参考图（ROG Cronox 官方产品图）的形态绘制线稿机箱，要求 **3D 可交互**、形态**高精度对齐参考照片**、具备**前沿技术设计感与科技感**，整体配色**符合全站暖纸工业图解风格**。
- **加载效果**：切换到「服务器」tab 时，机箱的线条**一笔一笔绘制出来**（stroke-by-stroke draw-on），绘毕进入交互态。

**取代**：首页机箱变形方向（像素→体素→纸板全链路终结）；「简笔画+像素」2D 三方向、「科技感舞台+产品图」方向均不再作为机箱本体方案（产品图方案仅存为形态参考资产）。

## Expected behavior

1. **导航与入口**：站点导航新增「服务器」tab/路由；页面标题即「服务器」，承载机箱舞台 + 五模块内容映射（见下节，风扇除外）。
2. **线条机箱（3D）**：线稿画风的 3D 机箱，形态精度对齐参考照片（侧透 3/4 视角识别度）；可拖拽环绕（小幅限角）、滚轮缩放；**不自转**（禁令沿用）。
3. **一笔一笔加载**：进入 tab 时线条按笔画顺序渐进绘出（目标 1.5–2.5s 完成），可带笔尖光点；绘毕淡入标注与交互层；`prefers-reduced-motion` 直切静态线稿。
4. **部件交互（2026-10-15 用户定案）**：默认 **45° 全景自动呈现**全部部件与常驻引线标注（编号+名称，投影跟随相机）；**点击部件 → 视角拉近**（相机推近该部件，保持 45° 视角语言、不做大幅旋转）+ **该部件线条继续丰富**——二级细节线随推近**一笔一笔绘出**，细节密度显著提升（鳍片/叶片/走线/丝印等微线出现）；关闭/Esc → 细节线收回、相机回 45° 全景。hover 预亮；就近信息卡（映射见下节「机箱即我」）。
5. **全站自然融合**（2026-10-16 用户修订）：统一暖纸底、墨棕线、少量牛血红；取消机箱专属渐变背景、边框和 HUD，透明模型直接嵌入页面，只保留脚下接触阴影。取消悬浮十字、游离长线、地面排线；线稿感仅来自真实结构边缘。见[全站视觉决策](warm-paper-illustration.md)。

## 内容映射（2026-10-16 用户定案：「机箱即我」五模块）

全景标注交互按同日反馈修订：引线使用水平—垂直—水平的直角横折，锚点与模型使用同一帧的相机矩阵，拖转保留亚像素精度，静置后保持稳定。点击部件或标签时，信息卡直接替换对应文字槽位，卡片与标签朝向机箱的一侧边缘重合；展开、切换和收起不改变引线端点。卡片宽度随舞台收窄，靠近底部时向上避让，保持连接处落在卡片边缘。手机沿用原位卡片。点击拉近与二级细节仍属 S5。

主题从「站点栏目向」改为**以用户为核心**：部件职能翻译成用户数字身份的职能，展示其作品与生态（中转站、JanusX 工作台等），不限于博客/站点栏目内容。交互形态同日定案：部件周围常驻「线+标识」介绍；**点击 → 视角拉近 + 该部件二级细节线以手绘 draw-on 方式渐进丰富 + 就近卡片呈现模块内容**；关闭/Esc 回 45° 全景、细节线收回。

## 约束

- 交互骨架复用已有结论：固定默认 45° 机位、常驻引线标注、就近卡片、无路由跳转本期照旧。
- 参考图（`_temp/design-demos/assets/rog-cronox/`，ROG 官方素材）**仅作形态研究**；成品线条/模型须自制或用授权资产，不直接商用 ROG 图形。
- **显卡形态基准**（2026-10-16 用户反馈厚重后修订）：以 [NVIDIA RTX 5090 Founders Edition 官方产品页](https://www.nvidia.com/en-us/geforce/graphics-cards/50-series/rtx-5090/)及其 gallery-shot-1/2 为形态参考，采用 **304×137mm、双槽横装**，替代上一轮 4090 三槽比例。双槽厚度建模近似取 40mm；局部尺寸 x/y/z≈20.28/5.92/45。保留站点暖土黄线稿配色，重建沙漏形框、双贯穿鳍片开口、底面双风扇、侧边 GEFORCE RTX 铭字与供电口、双槽 IO 挡板；细鳍片通过材质区分，不逐片叠粗描边，显卡主线 1.25px 且取消复描。整机形态标尺仍为 ROG 参考图。
- 技术栈 three.js（已在）；fat-lines 等扩展走 three examples 分发，不加新依赖。
- 全站保持浅色暖纸；服务器页共用页面底色，不再单独设置深色或渐变舞台。

## 整机部件与布局优化（2026-10-16）

用户继续要求优化整机，重点为 CPU、电源、内存和外壳，可参考 ROG 整机布局。本轮以 [ROG Cronox](https://rog.asus.com/us/cases/rog-cronox/) 的顶部冷排、侧面风扇、整洁理线和全景展示思路为主，辅以 [Hyperion GR701](https://rog.asus.com/cases/rog-hyperion-gr701-model/) 的电源仓展示窗思路；属于自制模型的布局适配，不宣称整机一比一复刻。

- CPU：贴板安装框、浅泵体、倒角面框和静态 CPU 铭屏，双水管连接顶部三风扇冷排；屏幕不伪造实时温度。
- 内存：四条 DIMM 仍归属 `mb` 部件，长轴沿 y，薄边沿 z，包含独立 PCB、散热马甲、细灯条、压纹和上下卡扣。主板配套调整 VRM / M.2 / PCIe / 供电位置。
- 电源：**替代上一轮“舱盖上放大电源”的布局**，本体收入底部独立仓；玻璃侧留展示窗，增加通气顶盖、理线孔和分别绕开显卡的主板 / GPU 供电线束。显卡底部至舱盖现约 18.39 单位；上节 1.29 的旧间距仅属旧布局证据。
- 外壳与风扇：保留两面玻璃和暖土黄线稿，减薄承力框，取消玻璃交会处遮挡内构的粗立柱；顶部由棋盘厚块改为细栅条，底脚改为金属滑橇。风扇为方框、薄唇口、七片弯叶及角部紧固件。显卡沿用此前 FE 模型。
- 描边：外壳 1.45px 保留轻微复描，其他部件 1.45px 单线，GPU 仍 1.25px；微型纹路、文字与叶片不叠粗轮廓，避免全景线条拥堵。

验证：`node _temp/verify-case-refinement.mjs`（本机现有 Playwright + Edge）通过；CPU / 内存及每个 VRM 实体 / 内存无包围盒穿插，泵体至内存 z 向间距约 3.4，内存至冷排 y 向间距约 7.32；电源本体 y=-43.25…-32.75，位于舱盖下、底板上。四 DIMM、三冷排风扇、三侧进风扇数量正确，所有几何顶点有限。桌面拖转 / 缩放、390×844 手机初始画布截图完成，页面运行及控制台错误 0。预览 `_temp/design-demos/case-refined-default.png`、`case-refined-side.png`、`case-refined-detail.png`、`case-refined-mobile.png`；日志 `_temp/case-refinement-browser-check.json`。手机机箱画布在视口内；另发现站点既有移出屏幕的 `nav-links` 导致文档横向溢出，本轮未改导航。

`npx astro check`：128 files、10 errors，模型相关文件无诊断；全仓检查仍因已有错误未通过。未重验整机点击聚焦、加载绘线及性能指标，未据此勾选总体验收。

## 开放项（待拍板）

- **视觉验收**：暖纸工业图解方向已由用户指定；具体观感仍由用户验收，全站共用色板，不再为 tab 单独设底色空间。
- **形态精度路线**：高精度模型资产（GLB）打底提线 vs 程序化精修几何提线（成本/上限见[实现分析](2026-10-15-idea-linecase-implementation--3f2a81c0.md)）。
- **笔画排序**：真笔画聚类 vs 空间扫描渐进（观感/成本差）。
- **拉近时的壳体策略**：推近看内构部件时，壳体/玻璃线淡化、剖切还是原样保留（影响细节可见性）。

## Acceptance criteria

- [ ] AC-1: 导航有「服务器」入口；进入后可见线条机箱，无首页变形路径残留。
- [ ] AC-2: 线条机箱 3D 可交互（拖转限角、缩放、引线标注常驻），形态辨识度对齐参考照片（水冷/显卡/风扇/LCD/电源仓可认）；**点击部件视角拉近，且该部件二级细节线渐进绘出、细节密度可见提升**；关闭后回 45° 全景、细节线收回。
- [ ] AC-3: 加载时线条一笔一笔绘出（1.5–2.5s 量级），绘毕交互可用；reduced-motion 直切静态。
- [ ] AC-4: 配色落在全站暖纸工业图解语义内，机箱直接融入页面，周围无悬浮十字或游离乱线（**以用户验收为准**）。
- [ ] AC-5: 交互帧率 idle median ≤16ms；`npx astro check` 10 error 基线不新增。
