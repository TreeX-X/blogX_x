# 需求：像素数码 3D 机箱 Hero——打散重组、部件交互与最佳视角

> **❌ 已取代（2026-10-15 晚）**：首页「像素标题变机箱」变形效果**已整体移除**（`index.astro` 还原为纯 `PixelWaveTitle`）；机箱归位**「服务器」tab**，新方向为线条画风 3D 可交互机箱——见[「服务器」tab 需求](2026-10-15-server-tab-linecase-requirement--103be143.md)。本 Note 全部保留作历史（含交付证据），不再作为有效目标。
>
> **⚠️ 部分方向变更（2026-10-15 交付后反馈）**：用户验收后提出五项问题（精度/美术、配色偏离 blog 语言、自转与逐件机位被否、变形生硬、布局让位生硬）。其中 **EB-5（自动旋转最佳展示位）与 EB-6（空闲自转）作废**，改为固定 45° 全景 + 常驻引线标注（2026-10-14 CALLOUTS 模型回归）；体素审美执行结果待重审。问题清单与成因分析见[想法 Note](2026-10-15-idea-case-hero-problems--7e447cfa.md)。AC-1/2/3/5/6/7 的既有证据保留；修复立项后回填修订。

## Goal

点击 hero「树码空间」后**原位**进入机箱体验（不换页、不遮罩）：知识图谱自动下移腾出舞台，标题像素打散并重组为一台**像素数码构成的 3D 高精度机箱**；点击零件亮起、放大，就近加载 UI 效果风格一致的介绍卡片；机箱自动旋转到该部件最佳展示位并为卡片腾位。

**取代 2026-10-14 的红橙纸板壳画风目标**——用户 2026-10-15 明确否决纸板画样式（「我不喜欢现在的纸板画样式。我希望是一个像素数码组成的 3D 高精度机箱」）。原需求 Note 见[历史需求](2026-10-14-home-case-hero-requirement--154e01dc.md)。

## Expected behavior

1. **布局腾位**：点击标题后不切换界面；知识图谱面板自动下移让出舞台空间（定案：机箱态切单列、舞台全宽在上、图谱过渡下移；移动端图谱从顶部移到舞台下方），过渡平滑、不闪烁。
2. **像素打散重组**：标题像素作为粒子场打散（爆散/湍流观感），随后逐个飞入组装成 3D 体素机箱；一次连续运动，无整页切换、无糊状中段（错峰 + 缓动）；支持逆向（机箱散回标题像素）。
3. **3D 高精度像素机箱**：机箱由像素/体素构成（GPU 实例化），精度足以辨识：外框、玻璃侧透、主板、显卡（含风扇叶）、CPU 水冷头与管路、冷排鳍片、电源仓、LCD 仪表屏（实况计数上屏）、前置 I/O 等细节。不用照片贴图、不用外部 GLTF 资产。
4. **部件交互**：hover 预高亮；点击零件亮起（发光/呼吸脉冲）并放大（该部件组微缩放，其余部件轻微弱化），旁边加载介绍卡片——卡片 UI 与像素数码风格一致；卡内展示映射文案（编号/名称/硬件职能/映射/LCD 计数），本期不设跳转（路由 chip 后置按需）。
5. **自动旋转最佳展示位**：点击部件后机箱自动旋转/运镜到该部件最佳展示角度；落位后为介绍卡片腾出空间（卡片就近 + 标识线，承接 2026-10-14 交互模型的就近原则），卡片不遮挡所指部件。
6. **空闲态**：未选中时机箱慢速自转；Esc / 返回按钮退出回标题。

## 内容映射（沿用，不随画风作废）

部件→栏目映射表沿用 [想法 Note](2026-10-14-idea-case-hero-concepts--60adaca4.md)：01 CPU 水冷头→AI 搜索管线、02 显卡→知识图谱、03 LCD 仪表屏→站点计数、04 侧置风扇组→氛围流、05 电源仓→关于我+灵感箱；备选库（RAM/主板/硬盘等）随 3D 新视角按需启用。LCD 计数数据继续由 `index.astro` 构建期下传。

## 约束

- 原位变化：不遮罩、不换页、不锁滚动（与 2026-10-14 形态决策一致，该部分仍有效）。
- 站点不引入暗色主题（`.agents/notes/constraints.md`）：体素配色收敛在暖纸 + 牛血 + 奶油 token（2026-10-15 定案：暖纸「像素陶瓷」，不设深色视窗面板；数码感由体素构成表达）。
- 新依赖仅允许 `three`（动态懒加载）；不引 react-three-fiber / drei。
- 移动端：点按选中、底部卡片、体素密度降档；知识图谱桌面端专属约束不变。
- `prefers-reduced-motion` 直切退化；帧率压测纳入验收（补 2026-10-14 AC-5 缺口）。
- `npx astro check` 不得新增报错（基线 10 error）。

## 定案回填（2026-10-15 用户拍板，详见[决策 Note](2026-10-15-decision-pixel-case-hero-direction--32ddac56.md)）

- **图谱下移形态**：✅ 全宽舞台——机箱态单列，舞台全宽在上，图谱过渡下移；移动端图谱移到舞台之后。
- **体素审美**：✅ 暖纸「像素陶瓷」——配色收敛在暖纸 + 牛血 + 奶油 token；数码感由体素构成表达，不设深色视窗面板。
- **卡片范围**：✅ 本期仅「点击部件旁就近出现介绍卡」；不设路由 chip、不做栏目/内容级跳转（跳转后置按需）。

- **部件扩容**：是否随 3D 新视角启用备选映射（RAM/主板/硬盘等）。
