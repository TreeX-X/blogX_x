# 想法：线条画风 3D 机箱的实现路线

> 分析记录（2026-10-15），对应需求：[「服务器」tab —— 线条画风 3D 可交互机箱](2026-10-15-server-tab-linecase-requirement--103be143.md)。定案前的探索，不是承诺。

## 核心结论

**线条机箱 = 底模提棱线（edge-line rendering）**：线条的精度永远等于底模的精度，所以「和参考照片高精度」是**模型问题**不是画线问题——先把形态做对（或买对），线条只是它的呈现层。交互骨架（限角拖转/射线拾取/引线标注/就近卡片）已在 `public/3d-poc/` 验证可直接复用。

## 技术路线

### 1. 形态来源（精度的根）

| 路线 | 精度上限 | 成本 | 说明 |
|---|---|---|---|
| A. 高精度 GLB 资产 | 图片级（catalog 图本是 3D 渲染） | 模型 $0–80 + 0.5 天接入 | TurboSquid/CGTrader/Sketchfab 采购或 CC 授权；形态直接对齐参考照片 |
| B. 程序化精修几何 | CG 可视级，难到照片 | 2–3 天建模 | POC 已验证管线；细节上限同 3d-poc 结论 |

**推荐 A**（或 A+B 混合：主体资产 + 个别部件程序化补）。参考图仅作形态标尺，成品不用 ROG 图形。

### 2. 线条渲染 · 双层线集（2026-10-15 交互定案后的核心结构）

**L1 轮廓线（常显）**：`EdgesGeometry(mesh, 高阈值)` 只挑硬棱——45° 全景的「简」，管远看构图。
**L2 细节线（交互触发）**：每部件的二级线集——低阈值边缘 + 手工铺的微线（鳍片阵/叶片曲线/PCB 走线/螺丝/丝印/格栅），默认 `drawRange=0` 不可见；**点击部件时一笔一笔绘出**——与 tab 加载同一「绘图机」动效语汇，故事线连续：进门画整机，点击画细节。

- 渲染：`LineSegments` + **`LineMaterial`（fat lines，three examples 自带，非新依赖）**：L1 线宽 2.5–3px 主色、L2 线宽 1–1.5px 次级色（石板色系内两级明度）；发光只给线条与接点，不铺霓虹。
- 曲面部件（风扇环/管路）调低阈值出轮廓弧；线集按部件分组（拾取/高亮/细节开关都按组走）。
- 可选面层：少数关键面半透明淡填充（玻璃面/屏面），避免纯线混沌。

### 2.5 点击拉近 × 细节丰富（交互签名动作）

一条时间线编排（与相机阻尼同拍）：

1. **t0**：相机 target→部件中心、dist 拉近（az/el 微调 ≤±10°，保持 45° 视角语言，禁大幅旋转）；
2. **t0+0.2s**：该部件 **L2 draw-on 0.8–1.2s**（setDrawRange 渐进，笔画序同 tab 加载）；细节标注（mono 小字）淡入；
3. **同步**：就近卡片到位；hover 预亮保持；
4. **Esc/关闭**：时间线倒放——L2 收回、相机回 45° 全景。

细节内容按部件设计（让细节「更多」而不只是「更粗」）：
- 01 CPU：冷排鳍片阵列线、泵盖剖面环、管路双线+卡箍、冷头丝印；
- 02 显卡：双风扇叶片线、背板肋条、PCB 走线示意、供电接口；
- 03 LCD：屏内 UI 线框（计数仪表线稿）、边框倒角；
- 04 风扇：每扇 9 叶曲线、轴承双环、四角螺丝、减震垫；
- 05 电源仓：格栅阵列、铭牌线稿、开关接口、线束曲线。

**壳体策略（开放项）**：推近内构部件时壳体/玻璃线可能挡视线——淡化（opacity 降）、剖切或保留，待定案。性能：L2 仅激活时绘制（每部件 1–3k 段），可控。

### 3. 一笔一笔绘制（tab 加载效果）

- **基础版**：`geometry.setDrawRange(0, n)` 随时间递增，线段按空间序（y 轴扫描或对角波次）渐进出现——「绘图机」感，1.5–2.5s，缓动取**线性偏机械**（绘图机不该 easeInOut 软飘）。
- **进阶版**：棱线段按端点聚类成连续折线「笔画」（union-find 合并共端点段），按笔画连续绘制 + **笔尖光点**（沿线插值的发光 sprite 走在笔尖）。
- 绘毕淡入标注/交互层；`prefers-reduced-motion` 直切静态线稿全显。
- 基础版可先行，笔画聚类是美化项可后补。

### 4. 交互（复用 3d-poc 骨架）

- 限角轨道相机（拖拽 ±50°/俯仰限幅/滚轮缩放，**禁自转**）；
- **拾取**：与线模同形的透明实体网格（opacity 0）做 raycast——线条本身太难点中；
- **部件高亮**：该部件线集的 linewidth/颜色/发光提升（按组材质）；点击 = 高亮 + 就近卡片（映射文案沿用）+ 可选**局部重绘**（该部件 drawRange 重演，科技感签名动作）;
- 常驻引线标注（编号+名称，3D 锚点投影到屏幕 + SVG 引线，POC 已验证）。

### 5. 石板色 + 科技感设计语法（待定案项）

- 「石板色」语义未定：深石板底（tab 有界深色空间）+ 浅线 vs 浅石板底 + 深线，二者都成立；
- 装饰层候选：网格地面、坐标刻度、mono 数据标注、悬停扫描线——每项都须 earn its place；
- 与主站暖纸+牛血的关系是**开放项**（新增 token 族 / tab 局部换肤），影响视觉验收标准。

## 交付分解（估算）

1. 形态定档（A 采购接入 / B 精修方案）：0.5 天
2. 线条渲染 + 石板色设计语言：1 天
3. 一笔一笔 draw-on 时间线：1 天
4. 交互层（拾取/高亮/卡片/标注）：0.5–1 天（3d-poc 复用）
5. 「服务器」tab 路由 + 导航 + 加载编排：0.5 天

→ **4–5 天量级**；资产采购/授权另计。

## 风险

- **精度 = 底模精度**：程序化路线的天花板就是 POC 展示的水平；要「图片级」必须模型先行。
- 笔画聚类性价比一般，基础版 drawRange 渐进已能交付「一笔一笔」观感。
- fat lines 性能：全机箱棱线约 5–15k 段可控；移动端降级普通线 + 减线密度。
- 「服务器」tab 若定深石板底，与「站点无暗色」约束的边界要在定案时写清（有界深色空间 vs 全站换肤）。
