# 首页使用单一知识地图与展开探索视图

## Context

首页读者需要在文章、知识库和关联网络之间连续探索。首屏与内容侧栏分别实例化全站图谱时，两份相同数据占据不同位置，缩放与节点选择互相独立；小型画布同时显示全部标签也容易挤压内容。图谱边框明确鼠标滚轮控制图谱与页面滚动的范围。

## Decision

`src/pages/index.astro` 使用共同的左右栏容器，右侧仅挂载一个 `KnowledgeGraph`。右栏在内容滚动时吸附于顶部 92px；面板高度受可用视口限制。屏幕宽度不超过 1024px 时，图谱收为可展开的入口。

展开视图复用同一个 SVG、模拟和缩放变换，固定 SVG 坐标系使尺寸变化不触发模拟重建。首页默认显示连接数靠前的六个节点标签；悬停、键盘聚焦或选择节点时显示其邻居，展开视图允许显示全部标签。鼠标位于整个图谱边框内时，普通滚轮控制图谱缩放并阻止页面滚动，包含标题、画布、详情和底部提示。边框外保留页面滚动。界面仅保留复位按钮，缩放沿用 D3 的滚轮增量和比例限制，鼠标位置转换为 SVG 坐标作为缩放中心。

节点点击与 Enter/空格先选择并预览，通过明确的阅读链接进入原文。图谱 API 从已有 `content` 字段提取最多 150 字符的纯文本片段，空片段使用提示文案。连线标注为语义相近，避免把向量相似度误读成引用关系。展开时背景内容设为 inert、锁定页面滚动并限制 Tab 焦点；关闭按钮和 Escape 恢复页面交互与原焦点。

首页图谱使用透明、无阴影的画布，以 1px、10% 不透明度的浅灰外边框和 8px 圆角界定范围，标题及操作入口使用小号灰字。界面不设置标题栏、详情栏和统计栏之间的分割线，也不显示节点数量和重复引导文案。未选中节点时隐藏详情区，仅在画布下方保留 0.6875rem 的灰色提示；选中节点后展示 0.8125rem 标题与 0.75rem 摘要。展开视图保留独立背景、圆角和遮罩以明确探索范围，内部依靠留白区分内容。

## Alternatives considered

保留两个图谱实例最容易复用既有布局，但读者在上下两处操作相同网络时无法延续状态，也需要两次数据请求。

首屏静态预览配独立探索页能进一步减轻首页负担，适合图谱只承担展示作用的博客。持续可用的右栏更符合首页探索内容的目标，因此展开视图保留在当前页面。

首屏全局图与下方当前文章的局部图能提供不同信息，但需要定义文章选择、局部数据范围和联动行为。单图方案直接保留探索上下文，避免增加第二套状态。

## Consequences

首页只维护一个图谱请求和交互实例。右栏贯穿首屏、功能介绍与内容列表，因此功能卡片也位于左栏，窄桌面使用单列卡片以保持可读性。

固定 SVG 坐标系保证展开前后的视角连续；小屏预览的标签随画布缩放，需要展开才能更清楚阅读。初始网络仍使用接口返回的全部节点，默认仅减少标签，并不删减关系数据。摘要是索引文本的开头片段，不是自动生成的内容总结。独立页面路由、搜索筛选和图谱数据聚类均不属于当前实现。

## Verification

`scripts/test-home-graph.mjs` 使用 12 节点模拟网络，检查单实例和单请求、键盘预览、展开前后缩放保留、背景 inert、Escape、92px 吸附、边框内滚轮缩放与边框外页面翻页、复位、390×844 移动入口、1280×600 矮屏以及加载失败和空数据。运行方式为先启动 `npx astro dev --host 127.0.0.1`，再执行 `node scripts/test-home-graph.mjs`。测试需要可用的 Playwright；外部安装可由 `PLAYWRIGHT_MODULE` 指定模块 URL，已有浏览器可由 `PLAYWRIGHT_EXECUTABLE` 指定。截图输出至系统临时目录。

真实 `GET /api/knowledge-graph` 返回 36 节点、126 条连线，所有节点均含不超过 150 字符的摘要字段。浏览器测试使用模拟接口验证交互，真实接口检查单独验证数据形状。

`npx astro build` 完成服务端构建和静态预渲染。构建期间既有文章相关推荐查询出现 SQL 错误并降级为空，不影响图谱测试。`npx astro check` 报告 10 项既有错误，分布在留言状态类型、首页文章可选日期和导航粒子空上下文；图谱组件及接口没有类型诊断，不能据构建成功视为仓库类型检查通过。

## Revisit signals

当节点数量使展开后的文字仍难以辨认，或读者需要保存和分享某个筛选视角时，再引入主题聚类、筛选与可寻址的独立探索页。需要真正摘要时，应在内容索引生成阶段维护摘要字段。
