# 决策：机箱 Hero 的画风、形态与变形编排

> **⚠️ 重审信号已触发（2026-10-15）**：「产品方向显式变更」成立——用户否决纸板画风、转向像素数码 3D 高精度机箱。Decision 1（红橙纸板壳画风）作废；Decision 2/4（原位变化、腾位+就近卡片交互模型）仍然有效；Decision 3 的「融化—盖印」编排被「打散—3D 组装」取代。新方向见[需求 Note](2026-10-15-pixel-case-hero-requirement--f47e324c.md)与[实现分析](2026-10-15-idea-pixel-hero-implementation--5d968c9f.md)；新决策已记：[决策：像素机箱 Hero 的舞台形态、体素审美与卡片范围](2026-10-15-decision-pixel-case-hero-direction--32ddac56.md)。

## Context

用户提出「点击首页『树码空间』变化为高精度可交互机箱，部件承载站点内容」（概念与映射脑洞见 [想法：机箱 Hero 的概念、映射脑洞与后续可能](2026-10-14-idea-case-hero-concepts--60adaca4.md)）。经设计咨询与三轮 demo 探索（v1 图+侧栏 / v2 引线腾位卡片 / v3 照片像素变形），四个维度的取舍需要定案。需求与验收见 [首页机箱 Hero 需求](2026-10-14-home-case-hero-requirement--154e01dc.md)。

## Decision（2026-10-14 用户逐项拍板）

**1. 画风 = 红橙纸板壳手绘 SVG。** 牛皮纸板模型语言——折边纸舌、瓦楞切面、胶带、丝印标注、齿孔切口、纸绳电源线。色板：face `#e0703f` / faceLight `#f0a878` / tray `#c85a30` / edge `#a84422` / deep `#7e2f14`，印色深可可 `#4a1a0e` + 奶油白 `#f8e8d8`；ox 血红仅留标注层（引线/编号）。发光描记用奶油聚光（红橙面上血红对比不足）。

**2. 形态 = 原位变化。** 点击标题后 hero 区在标题槽位**原地展开**为机箱（min-height 过渡），不遮罩、不换页、不锁滚动——导航/搜索/图谱栏/文章流全程在场。

**3. 变形编排 = 「融化—盖印」。** 标题像素自上而下融散（微下沉淡出）；机箱像素在各自目标位按对角波次盖印弹出（尺寸收小 + 目标色直接上色）；矢量 0.55–0.85 交棒锐化。逆向对称（机箱自右下融化、标题盖印回来）。全程一次连续运动。

**4. 交互 = 引线标注 + 腾开空间 + 就近卡片 + 卡片即标签 + 发光描记。** 机箱居中，部件带引线标注（编号 + 名称）；点击部件（本体/编号/引线/标签皆可点，引线带透明粗命中线）时机箱整体向对侧平移微缩腾开空间，卡片就近显示在标识线旁（纵向对齐引线端点）；聚焦态其余标签隐去（卡片即标签），编号仍可点；hover/选中时部件本体发光描记（奶油聚光 + 呼吸脉冲）。

## Alternatives considered

- **ROG 照片素材（热点标注版）**：demo v3 曾用官方产品图做底图。否决——用户明确「不是机箱图片」，照片不认得出是这个站；采集物仅存 `_temp/design-demos/` 作参照。
- **蓝图剖视（工程制图线稿）**：最初选定的 A 方向。后被纸板壳取代——纸板壳同样满足「精密 + 暖纸家族」，且材质叙事（手工纸模）比规格图更有这个站的性格。
- **真 3D（react-three-fiber + GLTF）**：写实渲染与 light-only 暖纸语言正面冲突；需模型资产；工作量数周。**重审信号**：产品方向显式变更为暗色渲染风时再开。
- **全屏 overlay 舞台**：demo v2/v3 的形态。否决——观感像「换了个页面」，与「首页不变的情况下变化」诉求冲突。
- **长途飞行 morph（像素逐格飞向目标）**：demo v3 编排。否决——密集目标格长距飞行中段必糊成色块；「融化—盖印」让糊状中段趋近于零。
- **全程像素爆炸图（B）/ 玻璃橱窗静物（C）**：咨询期另两方向，见想法 Note。

## Consequences

- LCD 丝印屏上屏站点实况计数（七集合），计数由 `index.astro` 构建期下传——仪表盘即内容盘点落在插画本体上。
- 像素取样在 http(s) 上下文对 SVG 栅格化 `getImageData` 无污染问题（demo 的 `case-pixels.js` 预采样是 file:// 权宜，产品不需要）。
- **成本与边界**：帧率未压测；无 `prefers-reduced-motion` 退化；卡片路由 chip 目前只到栏目级，内容级跳转待定（见需求 Note 开放项）。
- **重审信号**：出现低端机动画卡顿 → 加降级策略（直切/抽帧）；出现暗色产品方向变更 → 重开真 3D；部件映射要扩容 → 走想法 Note 的备选映射库。
