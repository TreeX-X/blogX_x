# 想法：机箱 Hero 的概念、映射脑洞与后续可能

> 探索记录。定案取舍见[决策 Note](2026-10-14-decision-case-hero-design--b56db041.md)，需求与验收见[需求 Note](2026-10-14-home-case-hero-requirement--154e01dc.md)。
>
> **📌 2026-10-15 附注**：画风方向已变更为像素数码 3D 机箱（见[新需求](2026-10-15-pixel-case-hero-requirement--f47e324c.md)）。本 Note 的映射脑洞与备选库**继续有效**；「真 3D」重审信号已触发（曾否决的 R3F/3D 路线以体素 3D 形式回归，实现分析见[想法](2026-10-15-idea-pixel-hero-implementation--5d968c9f.md)）。

## 起点（用户原始想法，2026-10-14）

「点击首页的『数码空间』（即 hero 像素标题『树码空间』）可以变化为一个高精度的机箱可交互结构，机箱的各个部分用于显示什么内容。」三轮追问收敛为：要**内置可交互的高精度机箱**（不是机箱图片），画风**纸板壳**、后又定为**红橙色**；**首页不变的情况下原位变化**，不做换页；入场要有「树码空间」像素变形效果并能变化回去。

## 映射脑洞：硬件职能 = 内容职能

机箱部件与站点栏目同构——部件的硬件职能就是栏目的内容职能。全表如下（前 5 项已落地为标注 01–05；其余是映射库，留待扩容时取用）：

|---|---|---|---|
| CPU 水冷头 | 思考核心 | AI 搜索与翻译管线（散热鳍片 = 向量索引 `blog_index`） | ✅ 01 |
| 显卡 | 渲染力 | 知识图谱（可视化即渲染） | ✅ 02 |
| LCD 仪表屏 | 实时仪表 | 站点内容计数（七集合实况上屏） | ✅ 03 |

## 咨询期的三方向（2026-10-14，设计顾问模式）

1. **精密蓝图剖视**（信息建筑派）：暖纸 + ox 血红线稿 + 尺寸标注，像放大的机箱规格图。——最初选定，后让位给纸板壳（规格图不如纸模有性格）。
2. **像素重组爆炸图**（运动诗学派）：像素字崩散 → 机箱沿轴线炸开成可点选爆炸图。——只取了它的过渡语言（像素变形），不取终点形态。
3. **玻璃橱窗静物**（东方极简派）：机箱作安静物件立在玻璃面板后，hover 才点亮。——未采用。

可行性三档当时定为：SVG 2.5D（数天，零依赖）／像素重组过渡（1–2 周）／真 3D R3F（数周，撞 light-only 约束）。落地取了「SVG 2.5D + 像素重组」的组合。

## Demo 探索足迹（`_temp/design-demos/`，仅参照非产品）

- **v1 图+侧栏**：ROG Cronox 官方产品照 + 热点 + 右侧面板。教训：用户要的不是照片；侧栏布局不像「就近标识线」。
- **v2 引线 + 腾开空间 + 就近卡片**：交互模型定稿的来源。教训：聚焦态「卡片即标签」；引线要透明粗命中线。
- **v3 照片像素变形**：像素字 ⇄ 机箱双向变形定稿的来源。教训：**密集目标格长途飞行必糊** → 后改为「融化—盖印」；file:// 下 canvas 读图片像素被污染（产品走 http 无此问题，`case-pixels.js` 预采样是 demo 专属权宜）。
- 素材事实档案：`product-facts.md` / `brand-spec.md`（ROG Cronox ARGB Dual TG，2026 官方产品页实抓）。

## 后续可能（未承诺，按需取用）

- **部件扩容**：备选映射库（RAM/主板/硬盘）与「未来」四件套（水冷回路/背线/前置 I/O/RGB 风扇）——需新视角（剖视/背板/正面）时一并设计。
- **内容级跳转**：卡片路由 chip 目前到栏目级（/posts 等）；点击「进对应栏目后高亮来源」或直达内容级（如 GPU → 图谱聚焦）待定。
- **动效调参**：变形时长、错峰节奏、像素颗粒度（现 10px）、聚光强度均可微调。
- **可及性与性能**：`prefers-reduced-motion` 直切退化；帧率压测（AC-5 缺口）；低端机降级策略。
- **双语**：卡片/标注文案的 en 版跟随 `LanguageToggle` 尚未做。
