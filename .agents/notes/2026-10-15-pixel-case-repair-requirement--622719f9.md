## 约束（沿用）

- 体素色值全部映射 `src/styles/global.css` token 族，不发明新颜色；站点浅色主题不动（`.agents/notes/constraints.md`）。
- 不引入新依赖（three 已在）；`prefers-reduced-motion` 直切退化保留。
- 原位变化形态（不遮罩不换页）与就近卡片（本期无路由跳转）不变。
- `npx astro check` 10 error 基线不新增。

## Acceptance criteria

- [ ] **AC-1 精度可辨识**：桌面典型宽度（≥1200px 视口）下细节清单逐项肉眼可辨、不呈噪点——外框、玻璃侧透、主板、显卡双风扇叶、水冷头与管路、冷排鳍片、电源仓、LCD 实况屏、前置 I/O；单体素视觉粒度 ≤8 CSS px（机箱显示宽度口径）。实例预算受 AC-6 帧率约束，由实现方裁量分档。
- [ ] **AC-2 配色符合 blog 画风**：牛血为箱体第一识别色、暖纸为主面；无大面积 ink/shadow 灰块读作「通用科技灰」；机箱对页面底色 `--bg` 图底可分、轮廓清晰；不设深色面板。**视觉以用户验收为准**。
- [ ] **AC-3 固定 45° 全景 + 常驻标注**：机箱态相机位姿恒定——无空闲自转、点击部件不改相机；固定约 45° 前脸-玻璃象限机位，五部件同框可辨；01–05 常驻引线标注（编号 + 名称，引线落部件旁、不遮挡部件）；hover 预高亮、点击亮起 + 就近卡片（无路由）。Esc / 返回按钮仍有效。**视觉以用户验收为准**。
- [ ] **AC-4 变形丝滑**：首次点击无空窗（标题保持到粒子接管，或场景预载）；标题像素按网格对齐采样、短程路径飞入目标位，无长弧爆散糊化中段；逆向（机箱散回标题）同样连续；reduced-motion 直切保留。
- [ ] **AC-5 让位自然**：知识图谱下移为一次连续过渡（无 grid 轨道跳变弹跳）；介绍卡一次定位到位（出现后不再二次跳动）；hero 展开、标题淡出、变形、图谱让位共用协调时间线；移动端底部卡片布局不回归。**观感以用户验收为准**。
- [ ] **AC-6 交互帧率**：机箱态 idle rAF dt median ≤16ms；变形期 dt p95 ≤20ms（压测记录留存）；移动端 lite 降档不掉档。
